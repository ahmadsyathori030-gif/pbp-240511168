
Aspek	Web	Desktop	Mobile
Bahasa utama	HTML, CSS, JavaScript (didukung framework seperti React, Angular, atau Vue) 	C++, C#, Java, atau Python (pemilihan bergantung pada kebutuhan performa dan pengembangan) 	Swift (iOS), Kotlin/Java (Android), atau Dart/JavaScript untuk pengembangan cross-platform 
Arsitektur	Client-Server, di mana browser sebagai klien mengirim permintaan ke server untuk diproses 	Aplikasi mandiri (standalone) yang berjalan langsung di atas sistem operasi tanpa bergantung pada server pusat untuk fungsi inti 	Arsitektur native atau cross-platform; aplikasi biasanya berjalan di perangkat dengan memanfaatkan API platform spesifik (kamera, GPS, dll.) 
Cara distribusi	Diakses melalui URL di browser; pembaruan dilakukan di sisi server sehingga pengguna selalu mendapat versi terbaru tanpa instalasi 	Melalui installer (seperti MSIX atau .exe) atau toko aplikasi seperti Microsoft Store 	Melalui App Store (iOS) atau Google Play Store (Android) 
Keunggulan	Akses universal lintas sistem operasi, tidak memerlukan instalasi, dan pembaruan instan 	Performa tinggi, akses penuh ke perangkat keras, dan dapat berjalan secara offline 	Portabilitas tinggi, dioptimalkan untuk layar sentuh, serta akses mudah ke sensor perangkat 
Keterbatasan	Bergantung pada koneksi internet dan memiliki keterbatasan akses ke perangkat keras 	Proses distribusi dan instalasi lebih sulit, portabilitas rendah (terikat OS tertentu), dan tidak dirancang untuk koneksi remote 	Layar perangkat relatif kecil dan pengembangan terpisah untuk setiap platform (jika native) 
Contoh aplikasi	Google Docs, Figma (versi web), Trello	Visual Studio Code, Discord, Slack	WhatsApp, Instagram, Gojek
